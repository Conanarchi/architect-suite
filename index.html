The tools

Twelve tools for the work nobody enjoys

Every tool opens in the same window and runs as one Undo step. AuditIt and MatchIt stay free after the trial.

TagIt

Tagging

Tag seven categories across as many views as you need, in one run.

  • Doors, windows, walls, floors, ceilings, furniture, lighting
  • Pick the tag family and type per category
  • Skips elements that are already tagged

JoinIt · UnjoinIt

Geometry

Join or unjoin walls, floors, columns and beams in bulk.

  • Active view, selection or entire model
  • Only elements that really intersect are joined

GrabIt

Coordination

Copy every column type from the structural link, ready for Copy/Monitor.

  • Preview: new types versus types already in the model
  • Copies only what is missing

MatchIt

Free

Copy one element's graphic overrides onto others, or clear them.

  • Pick a source and targets in the model
  • Works in the active view

StampIt

Revisions

Write approval, revision or phase values on all sheets at once.

  • Up to four parameters per run
  • {date}, {user} and {phase} fill in automatically

NumberIt

Numbering

Renumber doors, windows, parking or rooms in a logical order.

  • Left to right, bottom to top, or along a line you draw
  • Prefix, start, step, digits, with a live preview: D-01, D-02

AuditIt

Free

See what is slowing a model down, without changing anything.

  • Warnings, in-place families, imported and oversized CAD
  • Views not placed on sheets

FinishIt

Finishes

Create internal finish walls room by room.

  • Offset into the room, not room-bounding
  • Room height or a custom height in mm

ScheduleIt

Schedules

Create schedules for up to nine categories in one pass.

  • Sensible default fields per category
  • Never overwrites an existing schedule

ExportIt

Export

Export sheets and views to PDF, DWG, DWF, IFC and images with your own file names.

  • Paper size, orientation, placement and zoom, like Revit's own dialog
  • File names such as 001 - Ground Floor Plan
  • Stop at any moment: finished files are kept, nothing is left half written

DimensionIt

Dimensions

Dimension plans automatically, from quick concept sizes to detailed chains.

  • Concept: width and depth of every room
  • Detailed: walls, openings and grids in organised chains

SubmitIt

Submission

Get drawings ready for the municipality in three steps.

  • Capital letter for each word on names and titles, with a preview before anything changes
  • Hatches and text backgrounds removed only while exporting, then the model is restored
  • A drawing list (CSV) for your transmittal

Install

Two minutes, no IT ticket

  1. Close Revit.
  2. Download the installer and run it. It installs for your Windows user only and needs no administrator rights.
  3. Open Revit. The Architect Suite tab appears on the ribbon.
  4. The first time, Revit may ask about the add-in. Choose Always Load.
  5. After you buy, open SetupIt ▸ License, type your e-mail address, paste your key and press Activate.

FAQ

Questions people ask

Can I undo what a tool did?

Yes. Every run is a single Revit Undo step, named after the tool. Press Ctrl+Z once to revert the whole run.

What happens when the trial ends?

AuditIt and MatchIt keep working for free. The other ten tools show a short message with a link to buy Pro. Nothing in your models is affected, and you can still open everything you made.

Does it work on workshared models?

Yes, like any other edit. Make sure the elements are not borrowed by someone else, then sync as usual.

Is my model data sent anywhere?

No. Your model never leaves your computer. A licence key is checked on your PC without the internet. See the privacy policy.

Can I use it in my own language?

The interface is available in English, Arabic, French, Russian and Chinese. It works with any Revit interface language.

Do I need to pay again for each Revit version?

No. One licence covers every supported Revit version on your computer, including new releases while your licence is active.

How do I receive my licence key?

After payment, the key is sent to the e-mail address you paid with. In Revit, open SetupIt ▸ License, type that e-mail address, paste the key and press Activate. The key then works offline.

Can I get my money back?

Yes, within 14 days of purchase if it does not work for you. See the refund policy.
